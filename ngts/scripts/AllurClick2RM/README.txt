# AllurClick2RM

AllurClick2RM is a project that allows users to create Redmine issues directly from Allure reports with a single click.

## Directory Structure

This directory contains all the files used in this project:

- **plugin_files/** - Web plugin files that should be integrated into the user's web interface.
- **server/** - Server-side files that should be deployed on the HTTPS server.
