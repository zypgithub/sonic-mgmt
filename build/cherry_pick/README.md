# Cherry pick commits from sonic-mgmt community

This folder consists of the Python code and Jenkinsfile to automatically cherry
pick commits from [sonic-mgmt](https://github.com/sonic-net/sonic-mgmt) repository

The Jenkins pipeline name is
[sonic_community_auto_merge](https://nbuprod.blsm.nvidia.com/nbu-sws-sonic/job/sonic_community_auto_merge/)
